# Generative AI Research Project

This repository is used to organise and manage research materials for the study:
**"Using Generative AI Tools - Boon or Bane."**

## Project Structure

### 01_Literature_Review
Contains literature review materials, including journal articles, conference papers, books and other references.

### 02_Quantitative_Analysis
Contains survey data, survey questions, analysis scripts and quantitative analysis reports.

### 03_Qualitative_Analysis
Contains interview protocols, transcripts, qualitative analysis and data visualisations.

### 04_Drafts_and_Reports
Contains research proposals, conference paper drafts and final reports.

### 05_Additional_Materials
Contains information sheets, photos and other supporting media.

## File Organisation

Files should be stored in the appropriate folder and use clear and consistent file names.
When files are updated, meaningful commit messages should be used to describe the changes.

## Collaboration

Collaborators should:
1. Pull the latest version before making changes.
2. Store new files in the appropriate folder.
3. Use clear file names and meaningful commit messages.
4. Review changes before pushing them to the repository.
5. Use branches and pull requests when making substantial changes.

## Data Privacy

Sensitive research data, such as consent forms and identifiable participant information, should not be stored in a public repository and should only be accessible to authorised researchers.
